# Commands:-
- `mvn clean package` -- clean up old build output generated by previous builds, removes the target folder.
- `mvn validate` -- validate the project structure , pom file is present / not.
- `mvn compile` -- compiles the java application and checks for syntax-based errors.
- `mvn package` -- packages the compiled code into distributable format (.jar, .war)
- `mvn install` 
- `mvn deploy`
